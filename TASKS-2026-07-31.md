# mood8 — bug fixes & features (2026-07-31)

Fix these bugs and add these features in the Flutter app (~/projects/mood8).
Explore the code first, make minimal changes, keep the existing design, build/run to verify.

## 1) Bottom nav overlaps system bar (some phones, e.g. Samsung S24)
The phone's system navigation bar (back/home/recent) overlaps the app's bottom tab bar
(Today / Habits / Challenge / Coach / Progress) — tabs sit *under* it and are partly
unreachable. Fix by respecting the bottom safe-area inset: wrap the bottom nav in
SafeArea(bottom: true) or add padding = MediaQuery.of(context).viewPadding.bottom.
Verify with BOTH 3-button and gesture navigation.

## 2) Challenge — friends & invites
- Let a user search for friends by name/username, follow them, and invite them to a challenge.
- Send a DAILY PUSH notification (real OS push, outside the app — e.g. FCM) to every user
  who has joined a challenge, reminding them.
- If ALL participants of a challenge give up / leave, automatically remove (close) that challenge.
First check whether the backend supports users/friends/invites/push; if backend work
(endpoints, FCM setup) is needed, list what's required before implementing.

## 3) Challenge — usability
Users say they don't understand how to use the Challenge section. Redesign it to be
simpler and friendlier: clearer step-by-step flow, helpful empty states, obvious CTAs,
short inline hints.

## 4) First-run tutorial
Add an onboarding walkthrough shown the first time a user opens the app, explaining the
5 tabs (Today, Habits, Challenge, Coach, Progress).

## 5) Progress — "Top habits" layout bug
In the Progress section, the Top-habits cards clip/overflow: the percentage (e.g. under 3%)
and the habit name don't fit. Fix the layout so name + percentage always fit — handle
overflow, tiny values, and long names.

## 6) Tutorial should show exactly once per user
Currently the first-run tutorial doesn't reliably show to first users and/or repeats.
Persist a per-user "seen_tutorial" flag (local storage / account): show it once on first
entry, never again on later opens. Ensure existing users who never saw it get it one time.
